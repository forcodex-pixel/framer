# POE 顶层设计（汇总）

> 将各子模块设计整合为 POE 顶层视图，数据流自左向右：KO 指令入口 → 线程管理 → 一级/二级发射 → 执行单元。

## 1. 顶层数据流

1. **KO 指令入口**：KO 指令（6×8B）经 KOIU 进入；
2. **线程管理**：THM 建线程（≤32，满时 i_rdy 反压 KOIU），IFU 按 POE_HEAD 从 I_BUF_A 预加载 burst（每线程 2 深度）；
3. **发射**：ts_ctrl 判定发射条件 → th_sch 一级发射（≤2 burst/拍）→ 2 个 burst 队列（深度 8）→ burst_sch 二级发射；
4. **执行分流**：i/v_burst → EU（2×CU，SUB_PC 从 I_BUF_B 取子指令，mux/inst_b/demux 访问 RF）；c_burst → dma_ctrl（tsk_id 查 CSR，RBA 总线操作 DMA）；
5. **结果处理**：EU 结果送 tr → ts_ctrl 更新状态 / 写 O窗；dma_ctrl 读结果写 C窗。

## 2. 模块清单

| 模块 | 职责 |
| --- | --- |
| KOIU | KO 指令下发（预留 dma_ctrl 旁路） |
| THM | 线程管理 ≤32，burst 预取协调 |
| IFU | burst 预加载（每线程 2 深度） |
| I_BUF_A / I_BUF_B | 宏指令（burst）/ 子指令缓存 |
| ts_ctrl | 线程发射条件判定 |
| th_sch | 一级发射（≤2/拍） |
| burst 队列 ×2 | 深度 8 |
| burst_sch | 二级发射，按类型分流 |
| EU | 2×CU 执行 i/v_task |
| tr | 结果 / 跳转，更新状态 |
| dma_ctrl | c_task 执行（CSR 表 + RBA 总线） |
| RF / O窗 / C窗 | 寄存器文件 / 结果输出 / DMA 读结果 |
| DMA | RBA 总线对接的外部执行体 |

## 3. 关键机制

- **反压**：THM 32 线程锁定时 i_rdy 置 0 反压 KOIU；
- **双缓冲预取**：th_sch 发射当前 burst 时预取下一 burst；
- **两级发射**：一级（th_sch，2/拍）→ 二级（burst_sch）→ EU / dma_ctrl；
- **预留扩展**：KOIU → dma_ctrl KO 报文直连（预读 DMA 信息，减少拥塞）。
